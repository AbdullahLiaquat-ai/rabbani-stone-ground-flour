# Rabbani Stone-Ground Flour Management & E-Commerce System

A full-stack web application built for a traditional stone-ground flour business to digitize their local operations, manage customer orders, calculate delivery fees, and provide real-time analytics.

---

## 🚀 Key Features

* **Custom Admin & Mill Dashboard:** Live order tracking, status updates, and revenue analytics for business operators.
* **Smart Delivery Calculations:** Automated distance-based delivery fee calculations and unique tracking IDs for every order.
* **Direct WhatsApp Integration:** Streamlines bulk ordering and customer communication instantly.
* **Data Seeding Utilities:** Built-in Django management commands to instantly populate dummy data for testing and deployment.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django
* **Database:** SQLite
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
* **Version Control:** Git & GitHub
